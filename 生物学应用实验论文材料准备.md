# 生物学应用实验论文材料准备：独立 CTA Immune endpoint

> 状态：根据 `sctuner2.0/visualizations/bioapp_experiment/` 中 Phase 0-9、坐标注册审计、主图 V3.12 以及 downstream D0-D3 的现存结果整理。本文不依赖已删除旧实验结果。项目内部相对路径默认以 `sctuner2.0/` 为根。

## 0. 最终实验定位

本次生物学应用实验最初考虑 Xenium-defined B-lineage/humoral endpoint，但该候选在正式 CytoSPACE 映射可行性主线停止后被退休。最终完成并通过 Phase 9 审计的实验是：

- 数据：breast cancer Visium ST + computational pathology annotation（CTA）+ scRNA-seq reference。
- 外部 endpoint：CTA-defined `Immune cells`，由病理图像对象映射到 Visium spots 后冻结。
- 扰动条件：从 scRNA-seq reference 中删除全部 immune labels，形成 `immune-all-dropout`。
- Baseline：CytoSPACE 在缺少 immune reference 的条件下仍必须进行空间分配。
- SVTuner：Stage3B 在不使用 CTA endpoint、不按 endpoint 选阈值的前提下输出 spot-level unsupported/withheld score 与 binary withheld calls。
- 评价问题：SVTuner withheld behavior 是否与独立 CTA Immune endpoint 一致，并减少 baseline 在 CTA immune-positive spots 上的强制 non-immune assignment burden。

最终 Phase 9 允许的结论是：

> SVTuner provides biological-application evidence that its unsupported/withheld output is concordant with an independent CTA-defined Immune endpoint under an immune-all-dropout condition, reducing forced non-immune assignment burden relative to the baseline mapping.

这一结论有三个限定词不能删除：`independent CTA-defined endpoint`、`immune-all-dropout condition` 和 `withheld-aware burden estimate`。

## 2. 候选更替：从 Xenium/Janesick 到 CTA

Phase 0 共筛查 6 个候选：1 个 Tier 1、2 个 Tier 2、3 个 rejected。最初推荐 `Janesick Xenium-Visium breast cancer`，设想以 Xenium single-cell annotations 定义 B-cell、plasma-cell 或 humoral immune regions。

这一阶段只做外部 endpoint admission：

- 没有下载大型 raw data；
- 没有运行 CytoSPACE；
- 没有运行 SVTuner；
- 没有重新计算正式指标。

### 2.2 Phase 0R：Janesick 主线退休

由于 prior formal CytoSPACE mapping mainline stopped，Janesick 被明确标记为不再作为主生物学应用候选。随后重新排序 6 个既有候选并扩展筛查 4 个候选，最终推荐：

```text
Computational pathology annotation / breast cancer Visium CTA
```

这一步是实验设计纠偏，不是 endpoint 结果替换。论文或项目记录中不能把最初 Xenium 问题写成最终已完成实验。

## 3. Phase 1：endpoint 独立性与映射可行性

Phase 1 的门控结果为 PASS：

- endpoint 独立于 SVTuner；
- endpoint 独立于 CytoSPACE；
- endpoint 独立于 Visium expression；
- mapping 前可定义 endpoint-positive/negative spots；

### 9.4 Forced non-immune burden reduction

| 估计方式 | retained burden | prevented burden | fraction prevented |
|---|---:|---:|---:|
| binary withheld | 0.55224 | 0.44776 | 0.44776 |
| continuous withheld | 0.47944 | 0.52056 | 0.52056 |

## 12. Downstream D0-D3：探索性空间背景验证

这些实验不改变 Phase 8/9 主结果，只检验 withheld outputs 是否具有可解释的 morphology/interface/microenvironment context。

### 12.1 D0：冻结 morphology proxy 和 boundary

Domain 定义来自 CTA composition + 低分辨率 H&E patch features，不是病理学家标注。

| domain | spots |
|---|---:|
| tumor_core | 1,602 |
| immune_enriched | 312 |
| stroma_rich | 147 |
| mixed_boundary | 94 |
| unmapped_or_excluded | 93 |

boundary：217 seed spots、948 interface-band spots；nearest-neighbor median `7.2384` image pixels，neighbor radius `11.9434`，band width `9.0480`。

### 12.2 D1/D2：domain concordance 与 interface topology

immune_enriched 的 mean withheld score 为 `0.5013`、binary withheld rate `0.2821`；tumor_core 分别为 `0.3641` 和 `0.00687`。

统计检验：

- immune_enriched vs tumor_core withheld-rate difference：empirical p `0.0004998`，2,000 permutations。
- withheld-score effect size：Cohen's d `1.3153`，Cliff's delta `0.6420`。
- boundary-bin withheld-rate trend：Spearman rho `0.8503`，p `0.00747`；Kendall tau `0.7638`，p `0.00884`；one-sided permutation p `0.006997`。
- narrower/wider reporting bins 仍为正趋势，但 rho `0.5586`、p `0.1925`，稳健性弱于主冻结 bins。
- logistic regression 因 singular matrix 拟合失败，不能作为支持证据。

### 12.3 D3：unsupervised microenvironment contexts

使用不含 SVTuner outputs 的 local descriptors 做 `k=6` niche clustering，silhouette score `0.3557`。

最高 withheld-rate niche 为 `stroma_interface_niche`：76 spots，mean withheld score `0.5287`，withheld rate `0.3816`，CTA endpoint rate `0.1346`。

空间统计：

- withheld score Moran's I `0.4104`，empirical p `0.0004998`；Geary's C `0.5483`。
- binary withheld Moran's I `0.5681`，empirical p `0.0004998`；Geary's C `0.3485`。
- withheld spots 的 1-hop immune-associated niche neighbor fraction `0.5552`，null `0.1029`，z `23.65`，p `0.0004998`。
- 1-hop stroma-interface neighbor fraction `0.2084`，null `0.03380`，z `15.86`，p `0.0004998`。

这些结果支持“withheld outputs 具有非随机局部空间背景”，不能写成发现了新的病理 niche。

### Result 1: An independent pathology endpoint was frozen before mapping

报告 CTA-to-spot 注册、2,248 spots、134 positive/1,754 negative，以及 endpoint 未使用 expression/mapping outputs。

### Result 2: Reference immune dropout creates a forced non-immune baseline

### Result 3: SVTuner withheld scores recover independent immune-associated spatial signal

### Result 4: SVTuner reduces forced-call burden under the frozen perturbation

报告 44.78% binary 和 52.06% continuous burden prevention，并明确它们是 withheld-aware estimates。

## 14. 可直接用于论文的英文段落

> We froze a computational-pathology-derived immune endpoint before spatial mapping. Among 2,248 Visium spots, 134 were classified as immune-positive, 1,754 as immune-negative, 290 as ambiguous, and 70 as excluded. The endpoint was defined from registered pathology objects without using Visium expression, CytoSPACE assignments, or SVTuner outputs.

> We then removed all 2,414 immune cells from a 4,014-cell single-cell reference and retained 1,600 non-immune cells. Under this perturbation, the CytoSPACE baseline necessarily assigned a mean non-immune burden of 1.0 to the 134 endpoint-positive spots. SVTuner Stage3B was executed on 2,000 shared genes with its predefined FDR policy and without endpoint-guided threshold selection.

> SVTuner withheld scores were higher in endpoint-positive than endpoint-negative spots (0.521 versus 0.375; mean difference 0.145, bootstrap 95% CI 0.127-0.163; Cohen's d=1.317). The withheld score achieved an AUROC of 0.831 and an AUPRC of 0.284. Binary withheld calls occurred in 44.8% of endpoint-positive spots and 2.17% of endpoint-negative spots (odds ratio 36.2; Fisher's exact p=1.95e-49).

> Under a withheld-aware burden definition, SVTuner prevented 44.8% of forced non-immune calls using binary abstention and 52.1% using the continuous withheld score. These values quantify prevented forced-call burden and do not represent a post-Stage4 remapping estimate.

## 15. 写作边界

可以写：

- concordant with an independent CTA-defined immune endpoint；
- reduced forced non-immune assignment burden under immune-all-dropout；
- endpoint was frozen before mapping and not used for threshold selection；
- withheld outputs showed structured associations with frozen morphology proxies。

不能写：

- Xenium-defined B-lineage endpoint was successfully recovered；该候选已退休。
- SVTuner discovered new immune niches or signaling biology。
- 149 withheld spots 等同于 149 immune-positive spots。
- 52.06% burden prevention 是 post-remapping accuracy improvement。
- nonimmune dropout control 是 size-matched control。
- morphology domains 是 pathologist-annotated regions。
