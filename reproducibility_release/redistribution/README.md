# Redistribution

The authoritative redistribution matrix is
[`task4h_redistribution_matrix.tsv`](../release_candidate_v1.0/inventory/task4h_redistribution_matrix.tsv).

Only redistributable project code and project-generated quantitative
derivatives are included as files. Third-party records classified as
`LINK_AND_RECONSTRUCT`, `INTERNAL_NOT_FOR_RELEASE`, or
`UNRESOLVED_PERMISSION` are represented only through allowed provenance,
acquisition, checksum, and reconstruction metadata.

The release-package SHA-256 is recorded in
[`SVTuner-v1.0.0-rc1-reproducibility-package.sha256`](SVTuner-v1.0.0-rc1-reproducibility-package.sha256).
