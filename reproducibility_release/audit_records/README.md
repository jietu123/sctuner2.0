# Audit records

The selected public audit summaries are stored in
[`../release_candidate_v1.0/audit_summaries/`](../release_candidate_v1.0/audit_summaries/).

The authoritative inventory is
[`task4h_audit_record_inventory.tsv`](../release_candidate_v1.0/inventory/task4h_audit_record_inventory.tsv).
It contains 51 selected, hashed audit and provenance records.

Full local audit workspaces are intentionally excluded from Git. They include
execution-environment paths and working evidence that are not required for the
public release. Their selected public conclusions and checksums are already
represented in the frozen Task 4H candidate.
