# Data acquisition and reconstruction

No third-party raw dataset is bundled. Use the official source routes, sample identifiers and retained checksums in `../manifests/dataset_manifest_v1.0.tsv`, then run the preparation scripts under `../code/scripts/` with the formal configuration files.

Vizgen provider files are link-and-reconstruct only while explicit redistribution permission and provider checksums remain unresolved. CID4465 slide/capture area, CTA exact chemistry, and the human-lung run accession remain unresolved and must not be inferred.
