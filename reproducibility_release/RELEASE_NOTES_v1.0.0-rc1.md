# SVTuner v1.0.0-rc1

This is the manuscript-associated SVTuner reproducibility release candidate.

## Included

- Updated formal no-noise and 10% reference-noise benchmark records.
- Consolidated Stage3A, Stage3B, and CytoSPACE integration code and records.
- Frozen v1.0 dataset and experiment manifests.
- Fig. 1 through Fig. 5 source-value records and inventories.
- Selected audit summaries, environment specifications, configurations,
  reconstruction instructions, and checksum records.

## Public data boundary

This release does not include restricted third-party raw data, raw Vizgen
MERSCOPE provider files, complete GEO or 10x Genomics copies, complete Space
Ranger outputs, large raw expression matrices, or complete CytoSPACE
intermediates. Third-party inputs must be reacquired through the accessions and
official sources recorded in the frozen manifest.
